# QuickTranslate（畫面偵測翻譯）

QuickTranslate 是一個 Windows 桌面翻譯原型。將游標移到畫面上的單字，再按快捷鍵，程式會擷取游標附近的畫面、辨識文字並顯示詞典式翻譯。可用於影片字幕、圖片或其他無法直接選取文字的畫面。

## 目前功能

- 以 Tesseract OCR 辨識游標附近的文字，並從單字所在行擷取有限語境。
- 以 Ollama 本機模型產生詞典式結果：詞性、中文詞語與句子解釋、例句及例句翻譯。
- 過濾不含查詢詞或疑似模型提示文字的例句；例句缺漏時會再嘗試請模型補充。
- 詞義格式不符合預期時會要求模型修正一次；中文輸出會依繁體或簡體目標語言正規化。
- 翻譯結果顯示於游標旁的浮動視窗；長內容可捲動。
- 提供系統匣、快捷鍵設定、來源／目標語言選擇，以及繁體中文、簡體中文、英文、日文和韓文介面。

## 已知限制與待改善

- OCR 仍可能把相鄰文字、背景文字或辨識錯誤的字當成目標詞；目前已加入避免將翻譯浮層和部分終端機診斷文字讀回的處理，但複雜畫面仍需實際測試。
- 詞義和例句由本機語言模型生成，可能不準確、格式不合，或無法提供有效例句。格式修正與例句補救只能降低失敗機率，不能保證每次都成功。
- 沒有合格例句時，詞義仍可能顯示，但例句區塊會缺席。
- 缺少例句時會增加額外模型請求，因此翻譯可能變慢；辨識品質、模型速度與整體回應時間仍待改善。
- 英文詞形變化檢查採有限規則，遇到不規則變化時可能漏判。

## 開發環境與啟動

目前以 Windows 為目標，開發環境需要 Node.js/npm、Rust 工具鏈與 Windows C++ Build Tools。畫面辨識需要安裝 Tesseract OCR，並讓 `tesseract.exe` 位於預設安裝路徑或 `PATH` 中。

預設使用 Ollama 的 `qwen2.5:3b` 模型。程式啟動時會檢查 Ollama 和模型；如果找不到模型，會嘗試下載。首次下載需要網路連線。

在專案根目錄執行：

```powershell
npm install
npm run tauri dev
```

預設翻譯快捷鍵為 `Ctrl+Shift+T`，可在設定視窗中更改。

## 使用技術

- React、TypeScript：設定介面與浮動視窗
- Tauri：Windows 桌面應用程式與系統匣
- Rust：螢幕擷取、快捷鍵、OCR／翻譯流程及浮動視窗控制
- Tesseract OCR：畫面文字辨識
- Ollama：本機模型推論

## 專案狀態

目前仍是持續開發中的功能原型。主要流程、設定介面與詞典式翻譯格式已實作；接下來優先改善 OCR 選詞可靠度、詞義與例句品質，以及翻譯速度。
